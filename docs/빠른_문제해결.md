# 🚨 숲이 생성되지 않을 때 - 빠른 해결 방법

## 증상
- 숲 생성 명령을 실행했지만 아무 일도 일어나지 않음
- Output Log에 명령 처리 메시지가 없음

## 원인
**File Watcher Service**가 실행되지 않아서 명령을 처리할 수 없습니다.

---

## ✅ 즉시 해결하기 (1분)

### 방법 1: 간편 시작 (추천) ⭐

1. **프로젝트 폴더**에서 `MCPServer\scripts\StartFileWatcher.bat` 파일을 더블클릭
2. 검은 창(터미널)이 열리면서 다음 메시지가 나타남:
   ```
   🚀 File Watcher Service started
      Waiting for commands from UE5...
   ```
3. **이 창을 닫지 마세요!** (UE5 사용 중에 계속 열어둠)
4. UE5로 돌아가서 숲 생성 명령 실행

### 방법 2: UE5 Python 콘솔에서 시작

1. UE5 에디터에서 **Window → Developer Tools → Output Log**
2. **Cmd** 탭 클릭
3. 다음 코드를 복사해서 붙여넣고 Enter:

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path(r"<프로젝트경로>/UnrealProject/Content/Python")))
import init_unreal
```

> ⚠️ `<프로젝트경로>`를 실제 프로젝트 경로로 변경하세요!

4. 로그에 "🚀 File Watcher Service Started" 메시지 확인

---

## 🔧 영구적으로 해결하기

프로젝트에 `Config/DefaultEngine.ini` 파일이 추가되었습니다.
**UE5 에디터를 완전히 종료하고 다시 시작**하면 File Watcher가 자동으로 시작됩니다.

---

## ✅ 정상 작동 확인

File Watcher가 제대로 실행되면:

### 1. UE5 Output Log에서 확인
```
LogTemp: Warning: 🚀 File Watcher Service Started Automatically!
LogTemp: Warning: === NLPPCG System Ready ===
```

### 2. 터미널 창에서 확인 (방법 1 사용 시)
```
🚀 File Watcher Service started (poll interval: 0.3s)
   Waiting for commands from UE5...
```

### 3. 테스트 명령 실행

UE5 Output Log의 Cmd 탭에서:

```python
import unreal
lib = unreal.ForestPCGManagerLibrary
world = unreal.EditorLevelLibrary.get_editor_world()
lib.generate_forest_from_nlp(world, "밀집된 소나무 숲", unreal.Vector(0,0,0))
```

**File Watcher 터미널**에 다음 메시지가 나타나야 합니다:

```
============================================================
📨 Received command from UE5
   Command: 밀집된 소나무 숲
   Timestamp: 1234567890.123
   Parsed parameters:
      Tree Type: pine
      Density: dense
      Area Size: 100000000.0 cm²
      Min Distance: 200.0 cm
✅ Command processed successfully
============================================================
```

## ❌ 여전히 안 되는 경우

### 1단계: Python 환경 확인

터미널(CMD/PowerShell)에서:

```bash
cd F:\Project\Portfolio_MCP_PCG\MCPServer
python -c "from nlp_handler import ForestNLPHandler; print('OK')"
```

에러가 나면 패키지 설치:

```bash
pip install -r requirements.txt
```

### 2단계: ForestPCGManager 액터 확인

1. **World Outliner**에서 `ForestPCGManager` 액터 찾기
2. **Details 패널** 확인:
   - ✅ `Use File Communication` 체크됨
   - ✅ `Auto Create MCP Client` 체크됨
   - 📁 `Tree Meshes` 설정됨 (기본: Cube)

### 3단계: 레벨에 ForestPCGManager 추가

레벨에 액터가 없으면:

1. **Content Browser** → Plugins/NLPPCG Content
2. `BP_ForestPCGManager` 블루프린트를 뷰포트에 드래그
3. 원하는 위치에 배치

### 4단계: 로그 파일 확인

다음 파일들에서 에러 메시지 확인:

- `MCPServer/file_watcher.log` - File Watcher 로그
- UE5 Output Log - 전체 로그
- `Intermediate/MCP_Commands/` - 명령 파일 폴더 (있는지 확인)

## 💡 팁

### File Watcher가 실행 중인지 확인하는 방법

**Windows 작업 관리자**:
1. Ctrl+Shift+Esc
2. "프로세스" 탭
3. "python.exe" 프로세스 중 "file_watcher_service.py" 찾기

### UE5 종료 시 File Watcher도 함께 종료

- **자동 시작** (방법 2 사용 시): UE5 종료하면 자동으로 종료됨
- **수동 시작** (방법 1 사용 시): 터미널 창 닫거나 Ctrl+C

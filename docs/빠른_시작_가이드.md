# UE5 PCG 자연어 숲 생성 - 빠른 시작 가이드

## 🎯 목표

자연어 명령("밀집된 소나무 숲")으로 언리얼 엔진 5에서 PCG 기반 숲을 자동 생성합니다.

## 📋 사전 요구사항

- Unreal Engine 5.7
- Python 3.8 이상
- 필요한 Python 패키지 (`requirements.txt`)

## 🚀 시작하기 (3단계)

### 1단계: Python 패키지 설치

```bash
cd MCPServer
pip install -r requirements.txt
```

### 2단계: File Watcher Service 실행 ⭐ **중요!**

**UE5 에디터를 열기 전에** 이 서비스를 먼저 실행해야 합니다.

```bash
cd MCPServer
start_file_watcher.bat
```

다음과 같은 메시지가 나타나면 성공:
```
🚀 File Watcher Service started (poll interval: 0.3s)
   Waiting for commands from UE5...
   Press Ctrl+C to stop
```

**⚠️ 이 창을 닫지 마세요! 백그라운드에서 계속 실행되어야 합니다.**

### 3단계: UE5에서 숲 생성

1. **UE5 프로젝트 열기**
   - `Portfolio_MCP_PCG.uproject` 실행

2. **맵 열기**
   - `Content/Maps/M_MCP_PCG.umap` 열기

3. **ForestPCGManager 확인**
   - 레벨에 `ForestPCGManager` 액터가 있는지 확인
   - 없으면 액터를 배치: Content Browser → Plugins → NLPPCG → BP_ForestPCGManager

4. **숲 생성 명령 실행**

   **방법 1: 블루프린트 이벤트**
   - ForestPCGManager 선택
   - Details 패널에서 "Generate Forest From NLP" 버튼 클릭
   - 명령어 입력:
     ```
     밀집된 소나무 숲
     ```

   **방법 2: Python 콘솔** (추천)
   - Tools → Python (또는 Ctrl + P)
   - 다음 명령 실행:
     ```python
     import unreal

     # ForestPCGManager 찾기
     managers = unreal.EditorLevelLibrary.get_all_level_actors_of_class(
         unreal.EditorLevelLibrary.get_editor_world(),
         unreal.ForestPCGManager
     )

     if managers:
         manager = managers[0]
         # 숲 생성
         manager.generate_forest_from_nlp("밀집된 소나무 숲")
     ```

5. **결과 확인**
   - Output Log에서 다음 메시지 확인:
     ```
     📁 명령 파일 저장됨: 밀집된 소나무 숲
     📥 Received MCP response from file
     ```
   - 뷰포트에서 생성된 나무들 확인

## 🔍 문제 해결

### 숲이 생성되지 않는 경우

#### 1. File Watcher Service가 실행 중인가?

**확인 방법:**
- `MCPServer/start_file_watcher.bat`를 실행한 창이 열려 있는지 확인
- 창에 "Waiting for commands from UE5..." 메시지가 있는지 확인

**해결:**
```bash
cd MCPServer
start_file_watcher.bat
```

#### 2. UE5 Output Log 확인

**UE5에서:**
- Window → Developer Tools → Output Log
- "MCP" 또는 "NLPPCG"로 필터링

**정상 로그:**
```
LogTemp: Warning: === NLPPCG System Ready ===
LogTemp: Warning: ForestPCGManager: MCP Client bound to Forest Manager
LogTemp: Log: ✅ Command sent via file: ...
LogTemp: Log: 📥 Received MCP response from file
```

**에러가 있다면:**
```
LogTemp: Error: MCP Client not found!
```
→ ForestPCGManager의 "Auto Create MCP Client" 옵션 확인

#### 3. 파일 확인

**파일 위치:**
```
프로젝트폴더/Intermediate/MCP_Commands/
```

**확인 사항:**
- `ue5_command.json` - UE5가 생성 (명령 전송 후 삭제됨)
- `mcp_response.json` - Python이 생성 (처리 후 삭제됨)
- 파일이 생성되었다가 사라지는 것이 정상

**파일이 생성되지 않는다면:**
- UE5 MCPClient의 `bUseFileCommunication = true` 확인
- 파일 쓰기 권한 확인

#### 4. File Watcher 로그 확인

```
MCPServer/file_watcher.log
```

**정상 로그:**
```
📨 Received command from UE5
   Command: 밀집된 소나무 숲
   Parsed parameters:
      Tree Type: pine
      Density: dense
✅ Command processed successfully
```

## 💡 팁

### 1. 디버그 모드 활성화

ForestPCGManager Details 패널:
- `Debug Mode = true`

더 자세한 로그 확인 가능

### 2. File Watcher 자동 시작

매번 수동으로 시작하기 번거롭다면:

**Windows 작업 스케줄러 사용:**
1. 작업 스케줄러 열기
2. "기본 작업 만들기"
3. 트리거: "컴퓨터 시작 시"
4. 작업: `MCPServer/start_file_watcher.bat` 실행

### 3. 여러 숲 동시 생성

```python
import unreal

manager = unreal.EditorLevelLibrary.get_all_level_actors_of_class(
    unreal.EditorLevelLibrary.get_editor_world(),
    unreal.ForestPCGManager
)[0]

commands = [
    "밀집된 소나무 숲 500평방미터",
    "성긴 참나무 숲 300평방미터",
    "보통 자작나무 숲 400평방미터"
]

for cmd in commands:
    manager.generate_forest_from_nlp(cmd)
    unreal.SystemLibrary.delay(unreal.EditorLevelLibrary.get_editor_world(), 2.0)
```

## 🆘 도움이 필요하신가요?

### 일반적인 에러

| 에러 | 원인 | 해결 |
|------|------|------|
| "MCP Client not found!" | MCPClient가 초기화되지 않음 | ForestPCGManager 재배치 또는 `bAutoCreateMCPClient = true` |
| "NLP Handler not available" | Python 패키지 미설치 | `pip install -r requirements.txt` |
| "Failed to write command file" | 파일 권한 문제 | 관리자 권한으로 UE5 실행 |
| 숲이 안 생김 (에러 없음) | File Watcher 미실행 | `start_file_watcher.bat` 실행 확인 |

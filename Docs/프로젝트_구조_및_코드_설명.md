# Portfolio_MCP_PCG - 프로젝트 구조 및 코드 설명

## 프로젝트 개요

이 프로젝트는 **MCP(Model Context Protocol)**를 통해 **Cursor IDE/Claude AI**와 **Unreal Engine 5**를 연동하여, 자연어 명령으로 PCG(Procedural Content Generation) 기반 숲을 생성하는 시스템입니다.

### 핵심 기술 스택
- **Unreal Engine 5.5** - PCG 시스템을 이용한 절차적 숲 생성
- **Python 3.11+** - MCP 서버 및 자연어 처리
- **C++** - UE5 플러그인 (NLPPCG)
- **MCP (Model Context Protocol)** - AI와 UE5 간 통신 프로토콜

### 버전 정보
- **현재 버전**: v1.2.0
- **주요 업데이트**:
  - Self Pruning 노드 제거 및 바운드 기반 밀도 시스템 구현
  - 무한 재귀 방지 시스템 (PreloadMeshes)
  - Modify 명령어 지원 (밀도/크기 변경)
  - 혼합 숲 키워드 확장 ("다양하게", "믹스" 등)

### 통신 흐름

1. **사용자** → Cursor IDE에서 자연어 명령 입력 (예: "밀집된 소나무 숲 만들어줘")
2. **MCP 서버** → 자연어를 파싱하여 PCG 파라미터로 변환
3. **파일 통신** → `mcp_response.json` 파일로 명령 저장
4. **File Watcher** → 파일 감시하여 UE5로 전달
5. **UE5 Plugin** → PCG 시스템으로 숲 생성

is_modify = any(keyword in command for keyword in modify_keywords)

# 2. 이전 파라미터 로드
if is_modify:
    last_params = self._load_last_parameters()  # last_parameters.json 읽기

self._save_last_parameters(params)

return {
    "action": "modify_forest" if is_modify else "create_forest",
    "parameters": params

2. **바운드 기반 밀도 시스템**:
```cpp
// FPCGForestParameters 구조체에 추가
UPROPERTY(BlueprintReadWrite, EditAnywhere, Category = "Forest")
float DensityMultiplier = 1.0f;  // 밀도 배율

// ExecuteInternal()에서 밀도 처리
bool FPCGForestGeneratorElement::ExecuteInternal(FPCGContext* Context) const
{
    const UPCGForestGeneratorSettings* Settings = Context->GetInputSettings<UPCGForestGeneratorSettings>();
    const FPCGForestParameters& Params = Settings->ForestParameters;

    // 바운드 겹침 허용 여부 (밀도 > 1.0이면 허용)
    const bool bAllowBoundsOverlap = (Params.DensityMultiplier > 1.0f);

    // 밀도 기반 거리 조정
    // 수식: MinDistance = BaseMeshSize / √(DensityMultiplier)
    // 예: 밀도 2.0 → 거리 1/√2 = 0.707배 (약 30% 감소)
    //     밀도 0.5 → 거리 √2 = 1.414배 (약 40% 증가)
    float AdjustedMinDistance = Params.MinDistance;
    float AdjustedMaxDistance = Params.MaxDistance;

    if (Params.DensityMultiplier != 1.0f)
    {
        const float DensityScale = 1.0f / FMath::Sqrt(Params.DensityMultiplier);
        AdjustedMinDistance *= DensityScale;
        AdjustedMaxDistance *= DensityScale;
    }

    // Poisson Disk Sampling으로 포인트 생성
    auto IsValidPoint = [&](const FVector& Point, const FBox& NewBounds, float Scale) -> bool
    {
        // 1. 영역 경계 체크
        if (!BoundsBox.IsInside(Point))
        {
            return false;
        }

        // 2. 거리 기반 체크 (기존 로직 유지)
        for (const FVector& ExistingPoint : Points)
        {
            float Distance = FVector::Dist(Point, ExistingPoint);
            if (Distance < AdjustedMinDistance)
            {
                return false;  // 너무 가까움
            }
        }

        // 3. 바운드 기반 겹침 체크 (밀도 1.0 이하일 때만)
        if (!bAllowBoundsOverlap)
        {
            FBox WorldNewBounds = NewBounds.TransformBy(FTransform(Point));

            for (int32 i = 0; i < Points.Num(); i++)
            {
                FBox WorldExistingBounds = PointBounds[i].TransformBy(FTransform(Points[i]));

                // 바운드가 겹치는지 체크
                if (WorldNewBounds.Intersect(WorldExistingBounds))
                {
                    return false;  // 바운드가 겹침 (밀도 1.0 이하에서만)
                }
            }
        }
        // 밀도 > 1.0이면 바운드 겹침 허용 (bAllowBoundsOverlap == true)

        return true;
    };

    // Poisson Disk Sampling 실행...
}
```

## 주요 알고리즘

### 1. Poisson Disk Sampling (나무 배치)

`PCGForestGenerator.cpp`에서 사용하는 알고리즘:

```cpp
// 1. 그리드 기반 셀 시스템
float CellSize = AdjustedMinDistance / FMath::Sqrt(2.0f);
int32 GridWidth = FMath::CeilToInt(BoundsSize.X / CellSize);
int32 GridHeight = FMath::CeilToInt(BoundsSize.Y / CellSize);

// 2. 첫 번째 샘플 추가
FVector FirstPoint = GenerateRandomPointInBounds();
ActiveList.Add(FirstPoint);
Grid[GetGridIndex(FirstPoint)] = FirstPoint;

// 3. Active List에서 샘플 선택하여 주변에 새 샘플 생성
while (ActiveList.Num() > 0)
{
    int32 RandomIndex = FMath::RandRange(0, ActiveList.Num() - 1);
    FVector Point = ActiveList[RandomIndex];

    bool bFoundNewPoint = false;
    for (int32 k = 0; k < MaxAttempts; k++)
    {
        FVector NewPoint = GeneratePointAround(Point, AdjustedMinDistance, AdjustedMaxDistance);

        if (IsValidPoint(NewPoint, SelectedBounds, SelectedScale))
        {
            ActiveList.Add(NewPoint);
            Grid[GetGridIndex(NewPoint)] = NewPoint;
            Points.Add(NewPoint);
            PointBounds.Add(SelectedBounds);
            bFoundNewPoint = true;
            break;
        }
    }

    if (!bFoundNewPoint)
    {
        ActiveList.RemoveAt(RandomIndex);
    }
}
```

**장점:**
- 나무 간 최소 거리 보장
- 자연스러운 분포
- 효율적인 생성 (O(n))

**v1.2.0 개선사항:**
- 밀도에 따라 거리 동적 조정 (MinDistance = BaseMeshSize / √DensityMultiplier)
- 바운드 겹침 조건부 허용 (밀도 > 1.0)

### 2. 바운드 기반 밀도 시스템 (v1.2.0)

**기존 시스템 (v1.1.0 이하):**
- Self Pruning 노드가 바운드 겹침 제거
- 밀도 증가 시 나무 간격이 줄어도 Self Pruning이 걸러냄
- 결과: 밀도 증가가 실제 나무 개수에 반영되지 않음

**새 시스템 (v1.2.0):**
```cpp
// 1. 밀도 배율에 따른 거리 조정
const float DensityScale = 1.0f / FMath::Sqrt(DensityMultiplier);
AdjustedMinDistance = MinDistance * DensityScale;
AdjustedMaxDistance = MaxDistance * DensityScale;

// 예시:
// DensityMultiplier = 2.0 → DensityScale = 0.707 → 거리 70.7%
// DensityMultiplier = 0.5 → DensityScale = 1.414 → 거리 141.4%

// 2. 바운드 겹침 조건부 허용
const bool bAllowBoundsOverlap = (DensityMultiplier > 1.0f);

if (!bAllowBoundsOverlap)
{
    // 밀도 1.0 이하: 바운드 겹침 체크 (Self Pruning 대체)
    if (WorldNewBounds.Intersect(WorldExistingBounds))
    {
        return false;  // 겹침 방지
    }
}
// 밀도 > 1.0: 바운드 겹침 허용 (더 많은 나무 배치 가능)
```

**수학적 근거:**
- 나무 개수는 밀도에 비례: `N ∝ ρ`
- 나무 간 평균 거리는 밀도의 제곱근에 반비례: `d ∝ 1/√ρ`
- 밀도 2배 → 거리 1/√2 ≈ 0.707배 → 면적당 나무 개수 2배

### 3. 무한 재귀 방지 패턴 (v1.2.0)

**문제:**
```cpp
// SetupPCGGraph()에서 TreeMeshMap 설정
ForestSettings->TreeMeshMap = TreeMeshes;  // 프로퍼티 변경
   ↓
// PostEditChangeProperty() 트리거
PostEditChangeProperty()
   ↓
// PreloadMeshes() 호출
PreloadMeshes()
   ↓
// 메시 로드 중 프로퍼티 접근 → PostEditChangeProperty() 재호출
   ↓
// 무한 루프!
```

**해결:**
```cpp
// 1. 플래그 선언 (PCGForestGenerator.h)
UPROPERTY(Transient)
bool bIsPreloadingMeshes = false;

// 2. 재귀 방지 (PCGForestGenerator.cpp)
void UPCGForestGeneratorSettings::PostEditChangeProperty(FPropertyChangedEvent& PropertyChangedEvent)
{
    Super::PostEditChangeProperty(PropertyChangedEvent);

    // ⭐ 핵심: 이미 실행 중이면 스킵
    if (bIsPreloadingMeshes)
    {
        return;
    }

    if (PropertyChangedEvent.GetPropertyName() == GET_MEMBER_NAME_CHECKED(UPCGForestGeneratorSettings, TreeMeshMap))
    {
        PreloadMeshes();
    }
}

void UPCGForestGeneratorSettings::PreloadMeshes()
{
    if (!IsInGameThread()) return;

    // ⭐ 핵심: 재귀 체크
    if (bIsPreloadingMeshes)
    {
        UE_LOG(LogTemp, Warning, TEXT("PreloadMeshes() already in progress, skipping"));
        return;
    }

    // ⭐ 플래그 설정
    bIsPreloadingMeshes = true;

    // 작업 수행...
    CachedMeshes.Empty();
    CachedMeshBounds.Empty();
    for (const auto& Pair : TreeMeshMap)
    {
        // 메시 로드...
    }

    // ⭐ 플래그 해제
    bIsPreloadingMeshes = false;
}
```

## 성능 고려사항

### 나무 개수와 성능 (v1.2.0 기준)

**밀도 배율별 예상 나무 개수 (100㎡ 기준):**
- **밀도 2.0 (dense)**: ~800-1200 나무 (거리 70.7%, 바운드 겹침 허용)
- **밀도 1.0 (medium)**: ~400-600 나무 (거리 100%, 바운드 겹침 방지)
- **밀도 0.5 (sparse)**: ~100-200 나무 (거리 141.4%, 바운드 겹침 방지)

**공식:**
```
나무 개수 ≈ (영역 면적) / (나무 간 평균 거리²) × DensityMultiplier
평균 거리 = MinDistance × √(1 / DensityMultiplier)
```

### 최적화 팁
1. **InstancedStaticMesh 사용**: PCG가 자동으로 인스턴싱 처리
2. **LOD 설정**: 나무 메시에 LOD 적용
3. **Culling**: PCG의 자동 컬링 활용
4. **에셋 스트리밍**: 대형 프로젝트는 World Partition 사용
5. **밀도 제한**: DensityMultiplier > 3.0은 성능 영향 큼 (권장: 0.25 ~ 3.0)

### 메시 프리로딩
- `PreloadMeshes()`로 게임 스레드에서 메시 사전 로드
- `CachedMeshes` / `CachedMeshBounds`로 스레드 안전성 보장
- PCG 워커 스레드에서 안전하게 바운드 접근 가능

## 트러블슈팅

### 1. PCG 그래프가 생성되지 않음
**증상:** "Preloaded 5/5 tree meshes" 로그가 수십 번 반복, 에디터 멈춤

**원인:** PreloadMeshes() 무한 재귀

**해결:** v1.2.0에서 수정됨 (`bIsPreloadingMeshes` 플래그)

### 2. 밀도 증가해도 나무 개수 안 늘어남
**증상:** "밀도를 2로 변경" 해도 나무 개수 동일

**원인 (v1.1.0):** Self Pruning 노드가 바운드 겹침 제거

**해결 (v1.2.0):**
- Self Pruning 제거
- ForestGenerator에서 밀도 > 1.0일 때 바운드 겹침 허용
- 거리 자동 조정 (1/√DensityMultiplier)

### 3. Modify 명령어 작동 안 함
**증상:** "밀도를 2로 변경" 시 action: "create_forest"

**원인:** file_watcher_service.py에서 "변경" 키워드 미감지

**해결 (v1.2.0):**
- modify_keywords 추가
- last_parameters.json 저장/로드
- 파라미터 병합 로직 추가

### 4. 혼합 숲 안 됨
**증상:** "다양하게" 입력해도 단일 나무만 출력

**원인:** mixed_keywords에 "다양하게" 없음, tree_types 기본값 없음

**해결 (v1.2.0):**
- mixed_keywords 확장
- tree_types: [] 기본값 추가

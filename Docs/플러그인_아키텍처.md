## 개요

NLPPCG는 Unreal Engine 5.5 PCG 시스템을 기반으로 자연어 명령으로 절차적 숲을 생성하는 플러그인입니다.

### 핵심 설계 원칙
1. **모듈화**: Actor, PCG Node, MCP Client를 독립적으로 설계
2. **델리게이트 기반 통신**: 느슨한 결합으로 확장성 확보
3. **파일 기반 통신**: UE5와 Python 간 안전한 데이터 교환
4. **스레드 안전성**: PCG 워커 스레드와 게임 스레드 분리

### 플러그인 구조

**SetupPCGGraph() 상세 흐름** (v1.2.0):
```cpp
void AForestPCGManager::SetupPCGGraph(const FPCGForestParameters& Parameters)
{
    // 1. 기존 그래프 정리
    if (PCGComponent)
    {
        PCGComponent->Cleanup();
    }

    // 2. 새 PCG 그래프 생성
    UPCGGraph* PCGGraph = NewObject<UPCGGraph>(this, UPCGGraph::StaticClass());

    // 3. Input 노드 생성
    UPCGGraphInputOutputSettings* InputSettings = NewObject<UPCGGraphInputOutputSettings>(PCGGraph);
    UPCGNode* InputNode = PCGGraph->AddNode(InputSettings);

    // 4. Forest Generator 노드 생성
    UPCGForestGeneratorSettings* ForestSettings = NewObject<UPCGForestGeneratorSettings>(PCGGraph);
    ForestSettings->ForestParameters = Parameters;  // 파라미터 설정
    ForestSettings->BoundsSize = BoundsComponent->GetScaledBoxExtent() * 2.0f;
    ForestSettings->TreeMeshMap = TreeMeshes;  // 나무 메시 맵 전달

    // ⭐ v1.2.0: 무한 재귀 방지를 위한 메시 프리로드
    ForestSettings->PreloadMeshes();  // bIsPreloadingMeshes 플래그로 재귀 방지

    UPCGNode* ForestNode = PCGGraph->AddNode(ForestSettings);

    // 5. Static Mesh Spawner 노드 생성
    // ⭐ v1.2.0: Self Pruning 노드 제거됨
    UPCGStaticMeshSpawnerSettings* SpawnerSettings = NewObject<UPCGStaticMeshSpawnerSettings>(PCGGraph);
    SpawnerSettings->MeshSelectorType = EPCGMeshSelectorType::ByAttribute;
    SpawnerSettings->MeshSelectorParameters.AttributeName = TEXT("MeshPath");
    UPCGNode* SpawnerNode = PCGGraph->AddNode(SpawnerSettings);

    // 6. Output 노드 생성
    UPCGGraphInputOutputSettings* OutputSettings = NewObject<UPCGGraphInputOutputSettings>(PCGGraph);
    UPCGNode* OutputNode = PCGGraph->AddNode(OutputSettings);

    // 7. 노드 연결 (v1.2.0: Self Pruning 제거)
    // Input → ForestGenerator
    InputNode->GetOutputPin(PCGPinConstants::DefaultOutputLabel)->AddEdgeTo(
        ForestNode->GetInputPin(PCGPinConstants::DefaultInputLabel)
    );

    // ForestGenerator → MeshSpawner (Self Pruning 없이 직접 연결)
    ForestNode->GetOutputPin(PCGPinConstants::DefaultOutputLabel)->AddEdgeTo(
        SpawnerNode->GetInputPin(PCGPinConstants::DefaultInputLabel)
    );

    // MeshSpawner → Output
    SpawnerNode->GetOutputPin(PCGPinConstants::DefaultOutputLabel)->AddEdgeTo(
        OutputNode->GetInputPin(PCGPinConstants::DefaultInputLabel)
    );

    // 8. PCG 실행
    PCGComponent->SetGraph(PCGGraph);
    PCGComponent->Generate();

    UE_LOG(LogTemp, Log, TEXT("PCG Forest Generation Complete - Density: %s, DensityMultiplier: %.1f"),
        *Parameters.Density, Parameters.DensityMultiplier);
}
```

**ExecuteInternal() 상세 로직**:
```cpp
bool FPCGForestGeneratorElement::ExecuteInternal(FPCGContext* Context) const
{
    const UPCGForestGeneratorSettings* Settings = Context->GetInputSettings<UPCGForestGeneratorSettings>();
    const FPCGForestParameters& Params = Settings->ForestParameters;

    // 1. 출력 데이터 생성
    UPCGPointData* PointData = NewObject<UPCGPointData>();
    TArray<FPCGPoint>& Points = PointData->GetMutablePoints();

    // ⭐ v1.2.0: 밀도 기반 거리 조정
    // 수식: AdjustedDistance = MinDistance / √(DensityMultiplier)
    float AdjustedMinDistance = Params.MinDistance;
    float AdjustedMaxDistance = Params.MaxDistance;

    if (Params.DensityMultiplier != 1.0f)
    {
        const float DensityScale = 1.0f / FMath::Sqrt(Params.DensityMultiplier);
        AdjustedMinDistance *= DensityScale;
        AdjustedMaxDistance *= DensityScale;

        UE_LOG(LogTemp, Log, TEXT("Density adjustment: %.1fx → MinDist %.1fcm (from %.1fcm)"),
            Params.DensityMultiplier, AdjustedMinDistance, Params.MinDistance);
    }

    // ⭐ v1.2.0: 바운드 겹침 허용 여부
    const bool bAllowBoundsOverlap = (Params.DensityMultiplier > 1.0f);

    // 2. Poisson Disk Sampling 초기화
    const float CellSize = AdjustedMinDistance / FMath::Sqrt(2.0f);
    const int32 GridWidth = FMath::CeilToInt(Settings->BoundsSize.X / CellSize);
    const int32 GridHeight = FMath::CeilToInt(Settings->BoundsSize.Y / CellSize);
    TArray<FVector> Grid;
    Grid.SetNumZeroed(GridWidth * GridHeight);

    TArray<FVector> ActiveList;
    TArray<FVector> GeneratedPoints;
    TArray<FBox> PointBounds;

    // 3. 나무 타입 선택 (혼합 숲 지원)
    TArray<FString> TreeTypeList;
    if (Params.TreeTypes.Num() > 0)
    {
        TreeTypeList = Params.TreeTypes;  // 혼합 숲
    }
    else
    {
        TreeTypeList.Add(Params.TreeType);  // 단일 나무
    }

    // 4. 첫 번째 샘플 추가
    FVector FirstPoint = GenerateRandomPointInBounds(Settings->BoundsSize);
    ActiveList.Add(FirstPoint);

    // 랜덤 나무 타입 선택
    const FString& SelectedTreeType = TreeTypeList[FMath::RandRange(0, TreeTypeList.Num() - 1)];
    UStaticMesh* SelectedMesh = Settings->CachedMeshes.FindRef(SelectedTreeType);
    FBox SelectedBounds = Settings->CachedMeshBounds.FindRef(SelectedTreeType);
    float SelectedScale = FMath::FRandRange(1.0f - Params.Randomness, 1.0f + Params.Randomness) * Params.ScaleMultiplier;

    GeneratedPoints.Add(FirstPoint);
    PointBounds.Add(SelectedBounds);
    Grid[GetGridIndex(FirstPoint, CellSize, GridWidth)] = FirstPoint;

    // 5. Poisson Disk Sampling 루프
    const int32 MaxAttempts = 30;
    while (ActiveList.Num() > 0)
    {
        int32 RandomIndex = FMath::RandRange(0, ActiveList.Num() - 1);
        FVector Point = ActiveList[RandomIndex];

        bool bFoundNewPoint = false;
        for (int32 k = 0; k < MaxAttempts; k++)
        {
            // 랜덤 거리 및 각도로 새 포인트 생성
            float Distance = FMath::FRandRange(AdjustedMinDistance, AdjustedMaxDistance);
            float Angle = FMath::FRandRange(0.0f, 2.0f * PI);
            FVector NewPoint = Point + FVector(
                FMath::Cos(Angle) * Distance,
                FMath::Sin(Angle) * Distance,
                0.0f
            );

            // 랜덤 나무 선택
            const FString& NewTreeType = TreeTypeList[FMath::RandRange(0, TreeTypeList.Num() - 1)];
            UStaticMesh* NewMesh = Settings->CachedMeshes.FindRef(NewTreeType);
            FBox NewBounds = Settings->CachedMeshBounds.FindRef(NewTreeType);
            float NewScale = FMath::FRandRange(1.0f - Params.Randomness, 1.0f + Params.Randomness) * Params.ScaleMultiplier;

            // 유효성 검사 (IsValidPoint 람다)
            auto IsValidPoint = [&]() -> bool
            {
                // (1) 영역 경계 체크
                if (!BoundsBox.IsInside(NewPoint))
                {
                    return false;
                }

                // (2) 거리 기반 체크
                for (const FVector& ExistingPoint : GeneratedPoints)
                {
                    float Dist = FVector::Dist(NewPoint, ExistingPoint);
                    if (Dist < AdjustedMinDistance)
                    {
                        return false;  // 너무 가까움
                    }
                }

                // ⭐ v1.2.0: (3) 바운드 기반 겹침 체크 (밀도 1.0 이하일 때만)
                if (!bAllowBoundsOverlap)
                {
                    FBox WorldNewBounds = NewBounds.TransformBy(FTransform(NewPoint));

                    for (int32 i = 0; i < GeneratedPoints.Num(); i++)
                    {
                        FBox WorldExistingBounds = PointBounds[i].TransformBy(FTransform(GeneratedPoints[i]));

                        if (WorldNewBounds.Intersect(WorldExistingBounds))
                        {
                            return false;  // 바운드 겹침 (밀도 1.0 이하에서만 체크)
                        }
                    }
                }
                // 밀도 > 1.0: 바운드 겹침 허용

                return true;
            };

            if (IsValidPoint())
            {
                ActiveList.Add(NewPoint);
                GeneratedPoints.Add(NewPoint);
                PointBounds.Add(NewBounds);
                Grid[GetGridIndex(NewPoint, CellSize, GridWidth)] = NewPoint;
                bFoundNewPoint = true;
                break;
            }
        }

        if (!bFoundNewPoint)
        {
            ActiveList.RemoveAt(RandomIndex);
        }
    }

    // 6. PCGPoint 생성
    for (int32 i = 0; i < GeneratedPoints.Num(); i++)
    {
        FPCGPoint& Point = Points.Emplace_GetRef();
        Point.Transform = FTransform(GeneratedPoints[i]);
        Point.SetLocalBounds(PointBounds[i]);

        // 메타데이터에 MeshPath 저장 (MeshSpawner에서 사용)
        const FString& TreeType = TreeTypeList[FMath::RandRange(0, TreeTypeList.Num() - 1)];
        UStaticMesh* Mesh = Settings->CachedMeshes.FindRef(TreeType);
        if (Mesh)
        {
            Point.MetadataEntry = PointData->Metadata->AddEntry();
            PointData->Metadata->SetStringAttribute(Point.MetadataEntry, TEXT("MeshPath"), Mesh->GetPathName());
        }
    }

    // 7. 출력 반환
    TArray<FPCGTaggedData>& Outputs = Context->OutputData.TaggedData;
    FPCGTaggedData& Output = Outputs.Emplace_GetRef();
    Output.Data = PointData;

    UE_LOG(LogTemp, Log, TEXT("Generated %d tree points"), GeneratedPoints.Num());
    return true;
}
```

**PreloadMeshes() - 무한 재귀 방지** (v1.2.0):
```cpp
void UPCGForestGeneratorSettings::PreloadMeshes()
{
    // 게임 스레드 체크
    if (!IsInGameThread())
    {
        UE_LOG(LogTemp, Warning, TEXT("PreloadMeshes() must be called on Game Thread"));
        return;
    }

    // ⭐ 무한 재귀 방지: 이미 실행 중이면 스킵
    if (bIsPreloadingMeshes)
    {
        UE_LOG(LogTemp, Warning, TEXT("PreloadMeshes() already in progress, skipping to prevent infinite recursion"));
        return;
    }

    // ⭐ 플래그 설정
    bIsPreloadingMeshes = true;

    // 캐시 초기화
    CachedMeshes.Empty();
    CachedMeshBounds.Empty();

    // 메시 로드 및 바운드 계산
    for (const auto& Pair : TreeMeshMap)
    {
        const FString& TreeType = Pair.Key;
        const TSoftObjectPtr<UStaticMesh>& MeshPtr = Pair.Value;

        UStaticMesh* Mesh = MeshPtr.LoadSynchronous();
        if (Mesh)
        {
            CachedMeshes.Add(TreeType, Mesh);

            // 바운드 계산
            FBox Bounds = Mesh->GetBoundingBox();
            CachedMeshBounds.Add(TreeType, Bounds);

            UE_LOG(LogTemp, Log, TEXT("Preloaded mesh: %s (Bounds: %s)"),
                *TreeType, *Bounds.ToString());
        }
    }

    // ⭐ 플래그 해제
    bIsPreloadingMeshes = false;

    UE_LOG(LogTemp, Log, TEXT("Preloaded %d/%d tree meshes"),
        CachedMeshes.Num(), TreeMeshMap.Num());
}

void UPCGForestGeneratorSettings::PostEditChangeProperty(FPropertyChangedEvent& PropertyChangedEvent)
{
    Super::PostEditChangeProperty(PropertyChangedEvent);

    // ⭐ 무한 재귀 방지: 이미 PreloadMeshes 중이면 스킵
    if (bIsPreloadingMeshes)
    {
        return;
    }

    // TreeMeshMap 변경 시 메시 프리로드
    if (PropertyChangedEvent.GetPropertyName() == GET_MEMBER_NAME_CHECKED(UPCGForestGeneratorSettings, TreeMeshMap))
    {
        PreloadMeshes();
    }
}
```

```cpp
void AMCPClient::PollCommandFile()
{
    // 1. 파일 존재 체크
    if (!FPaths::FileExists(CommandFilePath))
    {
        return;  // 명령 없음
    }

    // 2. 파일 읽기
    FString JSONString;
    if (!FFileHelper::LoadFileToString(JSONString, *CommandFilePath))
    {
        UE_LOG(LogTemp, Error, TEXT("Failed to read command file: %s"), *CommandFilePath);
        return;
    }

    // 3. JSON 파싱
    TSharedPtr<FJsonObject> JsonObject;
    TSharedRef<TJsonReader<>> Reader = TJsonReaderFactory<>::Create(JSONString);

    if (!FJsonSerializer::Deserialize(Reader, JsonObject) || !JsonObject.IsValid())
    {
        UE_LOG(LogTemp, Error, TEXT("Failed to parse JSON"));
        IFileManager::Get().Delete(*CommandFilePath);
        return;
    }

    // 4. action 확인
    FString Action = JsonObject->GetStringField(TEXT("action"));

    if (Action == TEXT("create_forest") || Action == TEXT("modify_forest"))
    {
        // 파라미터 추출
        TSharedPtr<FJsonObject> ParamsObj = JsonObject->GetObjectField(TEXT("parameters"));

        FPCGForestParameters Parameters;
        Parameters.TreeType = ParamsObj->GetStringField(TEXT("tree_type"));
        Parameters.Density = ParamsObj->GetStringField(TEXT("density"));
        Parameters.AreaSize = ParamsObj->GetNumberField(TEXT("area_size"));
        Parameters.MinDistance = ParamsObj->GetNumberField(TEXT("min_distance"));
        Parameters.MaxDistance = ParamsObj->GetNumberField(TEXT("max_distance"));
        Parameters.Randomness = ParamsObj->GetNumberField(TEXT("randomness"));
        Parameters.ScaleMultiplier = ParamsObj->GetNumberField(TEXT("scale_multiplier"));
        Parameters.DensityMultiplier = ParamsObj->GetNumberField(TEXT("density_multiplier"));  // v1.2.0

        // ⭐ v1.2.0: tree_types 배열 처리 (혼합 숲)
        if (ParamsObj->HasField(TEXT("tree_types")))
        {
            const TArray<TSharedPtr<FJsonValue>>& TreeTypesArray = ParamsObj->GetArrayField(TEXT("tree_types"));
            for (const auto& Value : TreeTypesArray)
            {
                Parameters.TreeTypes.Add(Value->AsString());
            }
        }

        // 5. 델리게이트 발동
        OnForestGenerated.Broadcast(Parameters);

        UE_LOG(LogTemp, Log, TEXT("Forest parameters received: TreeType=%s, Density=%.1f"),
            *Parameters.TreeType, Parameters.DensityMultiplier);
    }
    else if (Action == TEXT("clear_forest"))
    {
        // ForestPCGManager의 ClearForest() 호출 (델리게이트 또는 직접 참조)
        UE_LOG(LogTemp, Log, TEXT("Clear forest command received"));
    }

    // 6. 파일 삭제 (중복 실행 방지)
    IFileManager::Get().Delete(*CommandFilePath);
}
```

## PCG 파이프라인

### v1.2.0 파이프라인 (Self Pruning 제거)

```
┌────────────┐    ┌───────────────────┐    ┌──────────────┐    ┌────────────┐
│ Input Node │───►│ ForestGenerator   │───►│ MeshSpawner  │───►│Output Node │
│            │    │ (Custom Element)  │    │ (Built-in)   │    │            │
└────────────┘    └───────────────────┘    └──────────────┘    └────────────┘
                           │                         │
                           │                         │
                  Poisson Disk Sampling      InstancedStaticMesh
                  Bounds Overlap Check        (Automatic Instancing)
                  DensityMultiplier
```

**각 노드 역할**:
1. **Input Node**: PCG 컴포넌트로부터 BoundsComponent 정보 전달
2. **ForestGenerator**: 나무 위치 포인트 생성 (Poisson Disk Sampling)
   - 밀도 배율 기반 거리 조정
   - 바운드 겹침 조건부 허용
   - 메타데이터에 MeshPath 저장
3. **MeshSpawner**: 각 포인트에 메시 스폰
   - MeshPath 속성 읽어서 메시 선택
   - InstancedStaticMeshComponent로 자동 인스턴싱
4. **Output Node**: 최종 결과 출력

## 메모리 관리

### 1. UObject 생명주기

**PCG 그래프 및 노드**:
- `NewObject<>()로 생성`: UE5 GC가 자동 관리
- `PCGComponent->Cleanup()`: 이전 그래프 및 인스턴스 제거
- `Outer` 설정: PCGGraph는 ForestPCGManager, Settings는 PCGGraph

**메시 참조**:
- `TSoftObjectPtr<UStaticMesh>`: Lazy Loading
- `CachedMeshes`: Raw Pointer (Transient, 게임 스레드에서만 접근)
- `PreloadMeshes()`: 명시적 로드로 PCG 실행 전 준비

## 스레드 안전성

### 1. 게임 스레드 vs PCG 워커 스레드

| 작업 | 스레드 | 설명 |
|------|--------|------|
| `PreloadMeshes()` | 게임 스레드 | `UStaticMesh::LoadSynchronous()` 호출 |
| `PostEditChangeProperty()` | 게임 스레드 | 에디터 프로퍼티 변경 시 |
| `ExecuteInternal()` | PCG 워커 스레드 | Poisson Disk Sampling 실행 |
| `CachedMeshes` 읽기 | PCG 워커 스레드 | 읽기 전용 (프리로드 완료 후) |

### 2. 스레드 안전성 보장 방법

**PreloadMeshes()에서 메시 사전 로드**:
```cpp
void UPCGForestGeneratorSettings::PreloadMeshes()
{
    // ⭐ 게임 스레드 체크
    if (!IsInGameThread())
    {
        return;

    // 메시 로드 (게임 스레드에서만 가능)

    }
}
```

## 3. 기본 사용법

4. 레벨 뷰포트로 드래그하여 배치

#### 방법 2: C++ Actor 직접 배치

1. **Place Actors** 패널 열기
2. 검색창에 "ForestPCGManager" 입력
3. 레벨로 드래그하여 배치

#### 배치 위치

- 숲의 **중심점**에 배치
- 월드 원점 (0, 0, 0) 또는 원하는 위치
- Z축 위치는 지형 높이에 맞추기

### 3.2 나무 메시 설정

ForestPCGManager를 선택한 후 **Details** 패널에서:

#### Tree Meshes 섹션

1. **Tree Meshes** 맵 확장
2. 각 나무 타입에 Static Mesh 할당:

| 키 (Key) | 나무 타입 | 할당할 메시 |
|---------|-----------|------------|
| `pine` | 소나무 | 소나무 Static Mesh |
| `oak` | 참나무 | 참나무 Static Mesh |
| `birch` | 자작나무 | 자작나무 Static Mesh |
| `maple` | 단풍나무 | 단풍나무 Static Mesh |
| `generic_tree` | 기본 나무 | 일반 나무 Static Mesh |

⚠️ **중요**:
- 메시를 할당하지 않으면 **기본 큐브**가 생성됩니다
- 모든 타입에 메시를 할당하는 것을 권장합니다

#### Auto Create MCP Client

- ✅ **체크**: MCP 클라이언트 자동 생성 (권장)
- ❌ **해제**: 수동으로 MCPClient Actor 배치 필요

#### Save PCG Graph As Asset

- ✅ **체크**: PCG 그래프를 에셋으로 저장
- ❌ **해제**: 런타임에만 그래프 생성 (기본값, 권장)

**JSON 파라미터:**

### 4.2 숲 수정 (Modify Forest)

**2024년 12월 최신 기능:**

기존 숲을 유지하면서 특정 파라미터만 변경할 수 있습니다.

#### 밀도 변경

```
밀도를 2로 변경
밀도를 0.5로 조정
```

**효과:**
- `밀도 2.0`: 나무 개수 2배 증가, 바운드 겹침 허용
- `밀도 0.5`: 나무 개수 0.5배, 더 드문드문 배치
- 기존 **나무 종류**, **영역 크기**는 유지

#### 크기 변경

```
나무 크기를 0.5배로 변경
나무 크기를 2배로 변경
```

**효과:**
- 나무 스케일만 변경
- 나무 개수, 종류, 영역은 유지

#### 복합 변경

```
밀도 2로 크기 0.5배로 변경
```

**효과:**
- 밀도 2배, 크기 0.5배 동시 적용

### 4.3 밀도 시스템 상세

#### 밀도 배율 (Density Multiplier)

| 밀도 | 간격 계산식 | 나무 개수 (상대적) | 바운드 겹침 |
|------|-------------|-------------------|------------|
| 0.5 | `BaseMeshSize * √2` | 0.5배 | ❌ 없음 |
| 1.0 | `BaseMeshSize` | 1배 (기준) | ❌ 없음 |
| 2.0 | `BaseMeshSize / √2` | 2배 | ✅ 허용 |

**BaseMeshSize**: 나무 메시의 바운딩 박스 평균 크기

**계산 원리:**
```
면적당 나무 수 ∝ 1 / (간격²)
따라서 간격 ∝ 1 / √(밀도)
```

**예시:**
```
밀도 1.0: BaseMeshSize = 650cm
  → MinDist = 650cm
  → 100㎡에 약 4,000 나무

밀도 2.0: BaseMeshSize = 650cm
  → MinDist = 650 / √2 ≈ 460cm
  → 100㎡에 약 8,000 나무 (2배)

밀도 0.5: BaseMeshSize = 650cm
  → MinDist = 650 * √2 ≈ 920cm
  → 100㎡에 약 2,000 나무 (0.5배)
```

#### 바운드 겹침 허용

**밀도 ≤ 1.0:**
- 나무 바운드가 겹치지 않음
- 자연스러운 간격 유지

**밀도 > 1.0:**
- 나무 바운드 겹침 허용
- 더 밀집된 숲 표현 가능
- 시각적으로 자연스러움 (나뭇잎 겹침)

### 4.6 Python 스크립트 통합

UE5 Python 콘솔 또는 스크립트:

```python
import unreal

# ForestPCGManager 찾기
managers = unreal.EditorLevelLibrary.get_all_level_actors()
forest_manager = None

for actor in managers:
    if isinstance(actor, unreal.ForestPCGManager):
        forest_manager = actor
        break

if forest_manager:
    # 자연어로 생성
    forest_manager.generate_forest_from_nlp("밀집된 소나무 숲")

    # 또는 파라미터 직접 설정
    params = unreal.PCGForestParameters()
    params.tree_type = "pine"
    params.density = "dense"
    params.area_size = 10000000000.0
    params.density_multiplier = 2.0

    forest_manager.generate_forest_from_parameters(params)
```

## 5. 명령어 레퍼런스

**혼합 숲 키워드:**
- 다양한, 다양하게, 다양
- 섞인, 여러 종류, 여러가지
- 혼합, 다종, 믹스

### 5.2 밀도

#### 키워드 방식

| 한국어 키워드 | 영어 코드 | 밀도 배율 | 설명 |
|--------------|-----------|----------|------|
| 빽빽, 밀집, 많은 | `dense` | 2.0 | 밀집된 숲 |
| 보통, 일반 | `medium` | 1.0 | 보통 밀도 |
| 듬성, 성긴, 적은 | `sparse` | 0.5 | 성긴 숲 |

#### 수치 방식 (권장)

```
밀도 1.0 = 기본 (메시 바운드 크기만큼 배치)
밀도 2.0 = 2배 많은 나무, 바운드 겹침 허용
밀도 0.5 = 0.5배 나무, 더 드문드문
```

**명령 예시:**
```
밀도를 2로
밀도 1.5
density 0.8
```

| 한국어 키워드 | 영어 코드 | 스케일 배수 |

| 큰 | `large` | 1.5x |

### 6.7 성능 문제 (FPS 드롭)

#### 증상
- 숲 생성 후 FPS 급격히 감소

#### 해결 방법

**1. 밀도 낮추기**

```
밀집 (2.0) → 보통 (1.0) → 성긴 (0.5)
```

**2. 면적 줄이기**

```
1000㎡ → 500㎡ → 100㎡
```

**3. Instancing 확인**

- PCG가 InstancedStaticMesh 사용하는지 확인
- Outliner에서 ISM 컴포넌트 확인

**4. LOD 설정**

나무 메시에 LOD 추가:
- LOD 0: 원본
- LOD 1: 중간 폴리곤
- LOD 2: 낮은 폴리곤

**5. Culling Distance**

```cpp
// 나무 메시 설정
Desired Max Draw Distance: 5000 (50m)
```

**6. 그림자 끄기 (멀리 있는 나무)**

```cpp
Cast Shadow: false (LOD 2 이상)
```

## 7. 성능 최적화

### 7.1 권장 설정

| 면적 | 밀도 | 나무 개수 (예상) | FPS 영향 | 권장 용도 |
|------|------|-----------------|----------|----------|
| 100㎡ | 0.5 | ~1,000 | 낮음 | 테스트 |
| 500㎡ | 1.0 | ~4,000 | 보통 | 일반 |
| 1000㎡ | 1.0 | ~8,000 | 높음 | 상급 |
| 1000㎡ | 2.0 | ~16,000 | 매우 높음 | 고사양 |

### 7.2 PCG 최적화 팁

**1. Instanced Static Mesh**
- PCG가 자동으로 인스턴싱 처리
- 같은 메시는 하나의 Draw Call

**2. 적절한 Bounds 설정**
- 너무 크면 불필요한 영역도 생성
- 너무 작으면 나무가 잘림

**3. Seed 고정**
- 같은 Seed = 같은 결과
- 재현 가능한 디버깅

### 7.3 메시 최적화

**1. LOD 레벨 설정**
```
LOD 0: 0-1000cm (0-10m)
LOD 1: 1000-3000cm (10-30m)
LOD 2: 3000-5000cm (30-50m)
```

**2. 폴리곤 수 제한**
```
LOD 0: 5,000 tris
LOD 1: 2,000 tris
LOD 2: 500 tris
```

**3. 텍스처 해상도**
```
Bark: 2048x2048
Leaves: 1024x1024 (알파 사용)
```

### 7.4 영역 분할

**큰 숲을 여러 작은 숲으로 분할:**

```cpp
// 10,000㎡ 대신:
ForestPCGManager x 10 (각 1,000㎡)

장점:
- 컬링 효율 증가
- LOD 전환 부드러움
- 메모리 분산
```

### 7.5 디버그 모드

**디버깅 시:**

```cpp
// MCPClient
bDebugMode = true;

// ForestPCGGenerator
// 로그 레벨: Verbose

Output Log:
🌲 Density-based spacing calculation:
   BaseMeshSize=650.5 cm
   DensityMultiplier=2.00x
   Final MinDist=460.0 cm
   Generated 15279 tree points
```

**프로덕션:**

